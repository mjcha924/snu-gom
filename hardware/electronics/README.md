# M2 electronics handoff

Record power/data schematics, regulator and connector ratings, branch current budgets, fuse/disconnect/low-voltage monitoring, IMU orientation, actual availability and quotes. Start with `docs/ELECTRONICS.md`.

Done means single-motor and one-leg tests have voltage-sag, peak-current and temperature logs that M3 can reproduce with the same wiring. Separate the ten-leg-motor budget from the optional two neck motors before purchasing.

# M2 전장 인수인계

전원·데이터 배선도, 레귤레이터와 커넥터 정격, 분기별 전류 예산, 퓨즈·차단·저전압 감시, IMU 장착 방향, 실제 재고와 견적을 기록합니다. `docs/ELECTRONICS.md`가 출발점입니다.

완료: 1축 및 한쪽 다리 시험에서 전압 강하·피크 전류·온도 로그를 확보하고 M3가 같은 배선으로 재현할 수 있음. 구매 확정 전 모터 10개와 선택 목 2개의 예산을 분리합니다.
