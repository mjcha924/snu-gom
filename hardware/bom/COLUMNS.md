# BOM column glossary / BOM 열 이름 안내

Numeric columns and IDs are shared by both languages. English text columns are translations, not separate budget rows. Update both descriptions together; do not add the Korean and English descriptions as separate purchases.
숫자 열과 ID는 두 언어가 공유합니다. 영문 텍스트 열은 번역이며 별도 예산 행이 아닙니다. 두 언어 설명을 함께 갱신하고 중복 구매로 합산하지 않습니다.

| CSV field / 열 | Meaning / 의미 |
| --- | --- |
| 번호 | Item ID / 항목 번호 |
| 구분 | Requirement: 필수 = required, 선택 = optional |
| 분류 | Category: 구동 = actuation, 기구 = mechanical, 외장 = shells, 제어 = control, 센서 = sensors, 전원 = power, 배선 = wiring, 시험 = testing, 충전 = charging, 예비 = spares, HRI = human–robot interaction |
| 품명 / item_en | Korean / English item name / 품명 |
| 규격 / specification_en | Korean / English specification / 규격 |
| 수량 | Quantity / 수량 |
| 단위 | Unit: 개 = piece, 팩 = pack, 조 = assembly/set, 식 = lot/set, 대 = unit |
| 선정상태 | Selection: 확정 = confirmed, 제안 = proposed, 미정 = undecided |
| 단가_원 | Unit price in KRW / 원화 단가 |
| 금액_원 | Line amount in KRW / 원화 금액 |
| 설계메모 / design_notes_en | Korean / English design notes / 설계 메모 |
| 구매_URL | Product or supplier URL / 제품 또는 판매처 URL |
| 링크유형 | 제품 / 후보 = product/candidate; 공통 재료 제품 = shared material; 판매처 / 규격 미정 = supplier, specification undecided |
| 가격근거 | Price basis: 제품 페이지 가격 = product page; 판매 목록 가격 = listing; 공통 재료 예산 = material pool; 공통 예산 포함 = included in pool; 예산 추정 = estimate; 판매처 = supplier; 후보 제품 = candidate; 검색 표시 가격 = search-displayed price; 품절 = out of stock; 포함품 기준 = based on included parts; 제품 가격 + 부속 예산 = product plus accessory allowance |
| 산정메모 / budget_notes_en | Korean / English purchasing assumptions / 산정 메모 |

Availability and prices were recorded on 2026-09-29, not re-quoted by the translation update.
재고와 가격은 2026-09-29 조사 기록이며 번역 작업에서 새로 견적을 받지는 않았습니다.
