# Historical SNU Bear V0.6

The superseded design had nine pitch joints and four limbs. Its code remains at `motion/`, meshes at `assets/v06_meshes/`, and playback at `scripts/simulate.py`. It is not the SNU GOM 10-axis biped. Archived Markdown retains its original text; some original relative links are historical. Use the pinned [pre-pivot repository](https://github.com/mjcha924/snu-gom/tree/95086d735ffeb571cfa295c385eeb72ce689d884) for a fully navigable snapshot.

Legacy tests and playback are retained for reproducibility. Old policy dimensions, joint names, calibration and checkpoints must not be passed to the biped. No legacy policy is claimed to be trained.
